# IPL 2022 Data Analysis

This project focuses on analyzing IPL 2022 match-level data using Python and popular data analysis and visualization libraries.

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📊 Project Overview

The project explores IPL 2022 match data to understand team performance, toss decisions, match results, player performances, winning margins, venue statistics, and scoring patterns.

## 🔍 Analysis Covered

* Dataset exploration
* Data cleaning
* Missing value analysis
* Duplicate checking
* Toss decision analysis
* Team-wise match performance
* Toss winner vs match winner
* Runs vs wickets victories
* Player of the Match analysis
* Top scorer analysis
* Bowling performance
* Venue analysis
* Match-winning margins
* Data visualization
